# Code of Conduct

AwareBC is built to help people get home safely. We want the place where it's built to feel the same way: respectful, helpful and safe for everyone.

## Be good to each other

- Be respectful and patient, especially with people who are new.
- Give feedback on the work, not the person.
- Assume good intent, and ask before assuming.
- Keep it on topic: AwareBC, its features, bugs and ideas.

## Not allowed

- Harassment, threats, insults or personal attacks.
- Hateful, sexual or violent content, or slurs of any kind.
- Posting anyone's private details (address, phone number, location, rider key) without their permission.
- Spam, ads, or trolling.
- Sharing security holes in public before they're fixed (see [SECURITY.md](SECURITY.md)).

The same rules apply inside the app. See the [Rider Rules](https://sinkid420.github.io/Singer-Flight-Tracker/privacy.html#rules).

## Where this applies

These rules cover this GitHub repository (issues, pull requests, discussions and comments) and any place you represent AwareBC.

## Reporting

If someone breaks these rules, email **awarebc.help@gmail.com** with links or screenshots. Reports are kept private.

## What happens next

Josh Singer, the project owner, reviews every report. Depending on what happened, the response can be a warning, removed comments, or a temporary or permanent ban from the project.
